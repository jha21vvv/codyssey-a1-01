## 1. NumPy 4D 이미지 축 축소 (Axis Reduction)
* **출처**: `src/pipeline.py` → `DataAnalyzer.extract_multimodal_features()`
* **공부해야 하는 이유**: `for`문 없이 수천 장의 이미지를 한 번에 계산하는 **벡터화(Vectorization)**의 가장 기본 패턴입니다.

```python
# [1차-단어분해]: tuple(범위 생성기)로 1부터 self.images.ndim(배열의 총 차원 수=4) 미만까지 정수를 묶어 (1, 2, 3) 튜플을 img_axes 변수에 저장합니다.
# [2차-예시/비유]: 4층짜리 아파트(0:사진번호, 1:세로, 2:가로, 3:RGB색상)에서 0번(사진번호)만 빼고 나머지 1, 2, 3번 축을 한 묶음으로 메모장에 적어둡니다.
img_axes = tuple(range(1, self.images.ndim))

# [1차-단어분해]: self.images(4D NumPy 배열)의 .mean(평균 메서드)에 axis=img_axes((1,2,3) 축을 따라 평균)를 넘겨 결과를 df DataFrame의 'img_mean' 컬럼에 대입합니다.
# [2차-예시/비유]: 2,000장 사진 각각의 가로·세로·RGB 숫자를 전부 합쳐서 사진 1장당 평균 밝기 숫자 1개(예: 214.09)로 꾹 눌러 압축해 표에 적습니다.
df["img_mean"] = self.images.mean(axis=img_axes)

# [1차-단어분해]: self.images의 .std(표준편차 메서드)에 axis=img_axes를 전달해 각 이미지 픽셀의 흩어짐 정도를 계산하고 df['img_std'] 컬럼에 저장합니다.
# [2차-예시/비유]: 사진 한 장 안에서 밝은 곳과 어두운 곳의 대비가 얼마나 큰지(명암 편차, 예: 64.13)를 2,000장 동시에 재서 표에 적습니다.
df["img_std"] = self.images.std(axis=img_axes)
```

## 2. NumPy 스트라이드 슬라이싱 다운샘플링 (리사이즈)
* **출처**: `src/pipeline.py` → `DataAnalyzer.extract_multimodal_features()`
* **공부해야 하는 이유**: OpenCV/Pillow 없이 배열 인덱스(`::step`)만으로 이미지 크기를 줄이는 **메모리·연산 최적화 기법**입니다.

```python
# [1차-단어분해]: if(조건문)으로 self.images.ndim(배열 차원 수)이 ==(같다) 4(4차원: 장수, 세로, 가로, 채널)인지 검사합니다.
# [2차-예시/비유]: 사진 상자가 (2000장, 세로 80, 가로 60, RGB 3색)처럼 4칸짜리 컬러 앨범인지 먼저 확인합니다.
if self.images.ndim == 4:

    # [1차-단어분해]: self.images[...] 슬라이싱에서 :(전체 장수), ::downsample_step(세로 step 간격), ::downsample_step(가로 step 간격), :(전체 RGB 채널)을 뽑아 downsampled에 저장합니다.
    # [2차-예시/비유]: step=2라면 모눈종이에서 가로·세로 한 칸씩 건너뛰며 점만 뽑아 (2000, 80, 60, 3) -> (2000, 40, 30, 3)짜리 1/4 크기 썸네일을 만듭니다.
    downsampled = self.images[:, ::downsample_step, ::downsample_step, :]
```

## 3. Pandas 문자열 벡터화 (`.str` 접근자)
* **출처**: `src/pipeline.py` → `DataAnalyzer.extract_multimodal_features()`
* **공부해야 하는 이유**: 텍스트 컬럼을 `for`문 없이 한 줄로 전처리할 때 `.fillna("").astype(str).str` 체이닝을 씁니다.

```python
# [1차-단어분해]: df[text_col](상품명 컬럼)에서 .fillna("")(결측값을 빈 문자열로 채움) 후 .astype(str)(문자열 타입으로 통일)을 적용해 text_series에 저장합니다.
# [2차-예시/비유]: 상품명 칸에 빈칸(NaN)이나 숫자가 섞여 있어도 에러 나지 않게 전부 ""(빈 글자)와 글자 타입으로 깔끔하게 통일합니다.
text_series = df[text_col].fillna("").astype(str)

# [1차-단어분해]: text_series의 .str(문자열 벡터 접근자)에서 .len()(글자 수 계산)을 호출해 df['name_length'] 컬럼에 저장합니다.
# [2차-예시/비유]: "Blue Shirt"면 공백 포함 10글자, "Red Bag"이면 7글자처럼 2,000개 상품명의 글자 수를 한 번에 셉니다.
df["name_length"] = text_series.str.len()

# [1차-단어분해]: text_series.str.split()(공백 기준으로 문자열을 단어 리스트로 쪼갬)한 뒤 다시 .str.len()(리스트 안 단어 개수 계산)을 호출해 df['word_count']에 저장합니다.
# [2차-예시/비유]: "Blue Cotton Shirt"를 띄어쓰기로 잘라 ["Blue", "Cotton", "Shirt"]로 만든 다음 단어 개수(3개)를 한 번에 세어 적습니다.
df["word_count"] = text_series.str.split().str.len()
```

## 4. GroupBy + `transform` 결측치 대치 & 2차 Fallback
* **출처**: `src/pipeline.py` → `DataAnalyzer.handle_missing_values()`
* **공부해야 하는 이유**: 그룹별 통계를 **원본 행 개수 그대로** 되돌려주는 `.transform()`은 결측치 대치의 핵심 문법입니다.

```python
# [1차-단어분해]: df.groupby(group_col)(카테고리별로 묶음)[col](단가 컬럼 선택).transform(strategy)(그룹별 중앙값/평균을 원본 행 수에 맞춰 복제 반환)를 group_stats에 저장합니다.
# [2차-예시/비유]: 신발 코너 상품 줄에는 '신발 중간가격($55)'을, 의류 코너 줄에는 '의류 중간가격($25)'을 각 줄 옆에 딱 맞춰 적어둔 임시 메모장입니다.
group_stats = df.groupby(group_col)[col].transform(strategy)

# [1차-단어분해]: df[col]의 .fillna(group_stats)(비어 있는 NaN 칸만 같은 행 위치의 group_stats 값으로 채움) 결과를 다시 df[col]에 덮어씁니다.
# [2차-예시/비유]: 가격표가 떨어진 신발(NaN)에만 옆에 적어둔 '신발 중간가격($55)'을 옮겨 적고, 원래 가격이 있던 상품은 그대로 둡니다.
df[col] = df[col].fillna(group_stats)

# [1차-단어분해]: 삼항 연산자(A if 조건 else B)로 strategy가 "median"이면 전체 중앙값(.median())을, 아니면 전체 평균(.mean())을 구해 global_val에 저장합니다.
# [2차-예시/비유]: 만약 특정 코너 상품 가격이 전부 비어있을 최후의 상황을 대비해, 매장 전체 상품의 대표 가격(예: $30)을 비상용으로 계산해 둡니다.
global_val = df[col].median() if strategy == "median" else df[col].mean()

# [1차-단어분해]: if pd.notna(global_val)(비상용 대표값이 NaN이 아닌 유효한 숫자인지 확인) 후 df[col].fillna(global_val)로 남은 결측치를 마저 채웁니다.
# [2차-예시/비유]: 코너별 대표가격으로도 못 채운 빈칸이 남아 있다면, 아까 구해둔 매장 전체 대표 가격($30)으로 마지막 빈칸까지 채워 넣습니다.
if pd.notna(global_val):
    df[col] = df[col].fillna(global_val)
```

## 5. IQR 이상치 탐지 및 이미지 배열 동기화 (`.to_numpy()`)
* **출처**: `src/pipeline.py` → `DataAnalyzer.detect_outliers()`
* **공부해야 하는 이유**: 이상치 울타리 계산과 함께, 표(`DataFrame`)와 이미지(`ndarray`)의 **인덱스를 어긋나지 않게 맞추는 실무 패턴**입니다.

```python
# [1차-단어분해]: series.quantile(0.25)(하위 25% 분위수)와 0.75(상위 25% 분위수)를 float(실수형)으로 변환해 각각 q1, q3에 저장합니다.
# [2차-예시/비유]: 가격을 싼 순서대로 줄 세웠을 때 1/4 지점(Q1, 예: $20)과 3/4 지점(Q3, 예: $44)의 경계값을 찾습니다.
q1 = float(series.quantile(0.25))
q3 = float(series.quantile(0.75))

# [1차-단어분해]: q3에서 q1을 뺀 사분위 범위(Interquartile Range)를 iqr 변수에 저장합니다.
# [2차-예시/비유]: 아주 싸거나 비싼 25%씩을 뺀 '가장 평범한 가운데 50% 가격대 폭($44 - $20 = $24)'을 구합니다.
iqr = q3 - q1

# [1차-단어분해]: q1 - iqr_multiplier * iqr(하한선)과 q3 + iqr_multiplier * iqr(상한선)을 계산해 정상 범위 경계를 만듭니다.
# [2차-예시/비유]: 가운데 폭($24)의 1.5배($36)만큼 양쪽으로 여유 울타리를 쳐서 하한(-$16)과 상한($80)을 정합니다.
lower_bound = q1 - iqr_multiplier * iqr
upper_bound = q3 + iqr_multiplier * iqr

# [1차-단어분해]: 비교 연산자(<, >)와 비트 OR(|, 또는)로 하한 미만 또는 상한 초과인 행만 True가 되는 불리언 마스크를 만듭니다.
# [2차-예시/비유]: 울타리(-$16 ~ $80) 바깥으로 툭 튀어나온 주문(예: $300)에만 True(이상치!) 도장을 찍어둡니다.
outlier_mask = (df[column] < lower_bound) | (df[column] > upper_bound)

# [1차-단어분해]: 비트 NOT(~)으로 이상치가 아닌(정상) 행만 True로 뒤집은 뒤, .to_numpy()로 순수 NumPy 불리언 배열로 변환해 self.images를 필터링합니다.
# [2차-예시/비유]: 표에서 이상치 줄을 지웠으면 사진첩에서도 똑같은 번호의 사진을 같이 빼야 짝이 안 어긋나므로, 정상(True) 사진만 남깁니다.
self.images = self.images[~outlier_mask.to_numpy()]
```

## 6. 동률 안전 RFM 분위수 점수화 (`rank(method="first")` + `pd.qcut`)
* **출처**: `src/pipeline.py` → `DataAnalyzer.calculate_rfm()`
* **공부해야 하는 이유**: 실무 데이터에서 `pd.qcut` 실행 시 동점자 때문에 에러(`Bin edges must be unique`)가 터지는 것을 막는 필수 테크닉입니다.

```python
# [1차-단어분해]: rfm["Recency"]의 .rank(method="first", ascending=False)(내림차순 정렬 후 동점자도 나온 순서대로 고유 순위 부여) 결과를 pd.qcut(..., q=4, labels=[1,2,3,4])로 4등분해 정수(.astype(int)) 점수로 변환합니다.
# [2차-예시/비유]: 최근 구매 경과일이 적은(가장 최근에 온) 손님이 높은 순위를 받도록 거꾸로 줄 세우고, 똑같은 날짜 손님도 대기표 번호로 구분해 1~4점을 안전하게 줍니다.
rfm["R_score"] = pd.qcut(
    rfm["Recency"].rank(method="first", ascending=False),
    q=4,
    labels=[1, 2, 3, 4],
).astype(int)

# [1차-단어분해]: rfm["Frequency"]를 오름차순(ascending=True)으로 대기표 순위(rank)를 매긴 뒤, qcut(q=4)으로 1~4점 등급을 부여합니다.
# [2차-예시/비유]: '1번 구매' 손님이 100명 중 70명이어도 대기표(1, 2, 3...)로 숫자를 다 다르게 만들어두었기 때문에 4등분 경계가 겹쳐 멈추지 않습니다.
rfm["F_score"] = pd.qcut(
    rfm["Frequency"].rank(method="first", ascending=True),
    q=4,
    labels=[1, 2, 3, 4],
).astype(int)
```

## 7. Seaborn 시각화용 `melt()` 데이터 구조 변환 (Wide → Long)
* **출처**: `src/visualize.py` → `generate_eda_charts()`
* **공부해야 하는 이유**: "처리 전"과 "처리 후" 두 컬럼을 하나의 그래프(박스플롯 등)에 나란히 그릴 때 가장 많이 쓰는 Pandas 변형 함수입니다.

```python
# [1차-단어분해]: pd.DataFrame({...})로 'Before IQR', 'After IQR' 두 컬럼을 가진 표를 만든 뒤, .melt(var_name='Stage', value_name='Unit Price (USD)')로 열 이름을 'Stage' 값으로 녹여 세로로 긴(Long) 표를 만듭니다.
# [2차-예시/비유]: 가로로 나란히 있던 [처리전, 처리후] 두 칸짜리 표를, [단계: 처리전/처리후, 가격: 숫자] 모양의 세로 2열 표로 길게 펴서 Seaborn이 색깔별로 박스플롯을 나란히 그릴 수 있게 만듭니다.
bp_df = pd.DataFrame(
    {"Before IQR": price_before, "After IQR": price_after}
).melt(var_name="Stage", value_name="Unit Price (USD)")
```
